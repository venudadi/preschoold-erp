# System Architecture & Documentation - prodv1_231225

**Date:** December 23, 2025
**Version:** 1.1 (Dynamic Configuration Update)

## 1. Project Overview
The Vanisris Preschool ERP is a comprehensive management system built with a **Node.js/Express** backend and **MySQL** database. It manages core preschool operations including student enrollment, attendance, financial management, and academic lesson planning.

## 2. Backend Architecture
The backend follows a modular, route-centric architecture.

- **Entry Point:** `backend/index.js` initializes the Express app, database connection pool, and mounts API routes.
- **Database:** Uses `mysql2` with a connection pool (`backend/db.js`).
- **Authentication:** JWT-based authentication with role-based access control (RBAC). Middleware: `backend/authMiddleware.js`.
- **Optimization:** Includes rate limiting (`express-rate-limit`), compression (gzip), and performance monitoring.
- **Environment:** Configuration via `.env` files with a dynamic fallback to database-stored `system_settings`.

### Key Directories
- `backend/controllers/`: Complex business logic (e.g., expenses, portfolio, 2FA).
- `backend/routes/`: Route definitions (e.g., `lessonPlanRoutes.js`, `authRoutes.js`).
- `backend/middleware/`: Authentication, security (`security.js`), and request processing.
- `backend/services/`: External integrations (Email, Claude API).
- `backend/utils/`: Security helpers and shared services (e.g., `settingsService.js`).

## 3. Lesson Planning Module (Enhanced)
A critical component handling the academic workflow from creation to execution and feedback.

### Key Features
- **Smart Templates:** Save successful plan structures as reusable templates (`lesson_plan_templates`).
- **Plan Cloning:** Quickly duplicate an existing week's plan to a new date range.
- **Auto-Forwarding:** Plans are automatically sent to assigned teachers upon submission, bypassing admin queues when possible.
- **Teacher "Today View":** Mobile-optimized endpoint providing only the activities scheduled for the current date.
- **Curriculum Analytics:** Aggregated engagement and rating data by activity category for coordinators.

### Database Schema
- **`lesson_plans`**: Core metadata and status tracking.
- **`lesson_plan_activities`**: Detailed daily pedagogical tasks.
- **`lesson_plan_assignments`**: Teacher-plan relationship.
- **`lesson_plan_feedback`**: Classroom execution results and teacher observations.
- **`lesson_plan_workflow`**: Immutable audit trail of all status changes.

## 4. Dynamic System Configuration
To eliminate the need for manual `.env` updates on the server, the system now supports database-backed configuration.

- **Table:** `system_settings` stores key-value pairs (e.g., SMTP host, port).
- **Security:** Sensitive values (like `smtp_pass`) are stored using **AES Encryption** (`CryptoJS`) in the database.
- **Service:** `settingsService.js` provides centralized access with a fallback to environment variables.

## 5. Critical Fixes & Stability (Dec 2025)

### Database & Backend
- **Collation Alignment:** Standardized all tables to `utf8mb4_0900_ai_ci` to resolve "Illegal mix of collations" join errors.
- **Schema Sanitization:** Removed invalid column references (e.g., `admission_date`) from legacy queries.
- **Rate Limit Adjustment:** Increased auth attempts to 50/15min for staging stability.

### Frontend & UX
- **Login Resilience:** Implemented timeout for authentication verification to prevent "hanging" login screens during server restarts.
- **Role-Based UI:** Refined Academic Coordinator views by hiding administrative actions (Pause/Promote/Transfer) and irrelevant modules (Enquiries).
- **CORS Support:** Explicitly allowed `x-2fa-totp` headers for secure multi-factor authentication.
